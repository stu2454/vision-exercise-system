What to do with a recording

The download is a canonical pose stream in the same JSON Lines format the Python recorder writes. Move it into recordings/ and it can be scored by the existing tooling:

python -m src.app score recordings/web_<id>.jsonl --no-start-gesture

Record the same movement in both runtimes and compare. Any difference is the browser runtime, not the model — both load the identical pose_landmarker_lite.task file from models/.
